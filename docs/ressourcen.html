NoRisk Addon Lib

Eine Java-Library zum schnelleren Erstellen von Add-on-Modulen, HUDs und Einstellungen. Die Spieler benötigen keine separate Library-Mod, wenn das Add-on die Library-Klassen in sein eigenes Mod-JAR bündelt.

  • Anleitung, API und Beispielcode
  • norisk-addon-lib-1.0.0.jar – fertige Library
  • norisk-addon-lib-1.0.0-sources.zip – Quellprojekt und Gradle Wrapper
  • Wiki-Quellcode auf GitHub
Die NRC-Client-, owo-lib-, Abstraction- und Kotlin-JARs sind keine Bestandteile der Library-Downloads. Beziehe sie nur aus deiner rechtmäßig verfügbaren Add-on-Entwicklungsumgebung; diese privaten/versionsabhängigen JARs werden hier nicht weiterverteilt.
